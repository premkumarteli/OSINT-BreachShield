# BreachShield - Workspace Rules & Guidelines

## Automatic Git Push Requirement
- **Always push after completing work:** Upon completing any coding task, bug fix, refactor, or user request, you must:
  1. Stage and commit all changes with a descriptive conventional commit message (e.g. `feat: ...`, `fix: ...`, `chore: ...`).
  2. Push the commits to GitHub across both configured remotes on branch `main`:
     - `breachshield` (`https://github.com/premkumarteli/breachshield.git`)
     - `origin` (`https://github.com/premkumarteli/OSINT-BreachShield.git`)
  3. Verify that the working directory is clean and both remotes are up to date.
